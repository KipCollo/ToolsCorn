# Web Design & Framework

`Web designers` create the overall look and feel of a website.
`Web developers` implement the design using HTML, CSS and JavaScript code.

Major pillars of web design are -

1. Typography
2. Colors
3. Images/Illustrations
4. Icons
5. Shadows
6. Border Radius.
7. White space
8. Visual Hierarchy
9. User Experience
10. Components & Layouts.

## Typography

Typography is the art and technique of arranging type to make written language legible, readable and appealing when displayed.

_Font types_ -

- `Serif vs Sans-serif` -
  - serif typeface - Creates a traditional/classic look and feel.Conveys trustworthiness. Good for long text.
  - Sans-serif - Modern look and feel.Claen and simple.

- `sans-serif` -

1. Inter.
2. Open Sans
3. Roboto
4. Montserrat
5. Works Sans
6. Lato

- `Serif` -

1. Merriweather
2. Aleo
3. Playfair Display.
4. Cormorant.
5. Cardo
6. Lora.

_Font sizes & Weights_ - For font-sizes, use a type scale tool or other pre-defined range.

1. Normal text - between 16px and 32px.
2. Long text - 20px or bigger.
3. Headlines - 50+px and bold(600+)
4. Any text, don't use a font weight below 400

## Colors

Colors convey meaning.Use a good color tone.
Tools - Open color, tailwindcss, flat ui colors 2, palleton.com, coolors, tint & shade generator.

You need at least two types of colors in color palette: main color and a grey color.You can add more colors(ascent colors).
For diversity,create lighter and darker versons(tints and shades).

Use main color to draw attention to most important elements on the page.I.e buttons, logos.
Use colors to add interesting accents or make entire components or sections stand out.

## Images & Illustrations

Different types of images: product photos, storytelling photos, illustrations, patterns.
Image tools:- Unsplash, Pexels, Drawkit, unDraw, Squoosh(compressing tool).

Texts on images:-

1. Darker or brighter the image(completely or partially using gradient)
2. Position text in neutral area.
3. Put text in a box.

## Icons

Use SVG icons or icon fonts because they scale indefinately. Don't use bitmap image formats(.jpg or .png).
Icons toolbox:- Phosphor icons, ionicons, icons8.

- Use icons to provide visual assistance to text.
- Use icons for product feature blocks.
- Use icons associated with actions, and label them.
- Use icons as bullet points.

To keep icons neutral, use same color as text.To draw more attention, use different color.
Don't make icons larger than what they were designed for.If needed, enclose them in a shape.

## Components & Layouts

Elements ----> Components ------> Layouts ----Webpage

Use common `elements` and `components` to convey your website’s information.Combine components into `layouts` using common layout patterns.Assemble different layout areas into a complete, `final page`.

_Elements_ - The most common elements are:- Text, Buttons, Images, Input Elements,Tags.
_Components_ - Commons components includes:- Breadcrumbs, Pagination,Alert & status bars,Statistics,Gallery,Feature box,Preview & profile cards,Accordion,Tabs,Carousel,Customer testimonials,Customer logos,Featured-in logos,Steps,Forms,Tables,Pricing tables,Modal windows.
_Section components_ - Navigation, Hero section,Footer,Call-to-action section,Feature row.
_Layout patterns_ - Row of boxes or cards,Grid of boxes or cards,Z-pattern,F-pattern,Single-column,Sidebar,Multi-column/magazine,Assymetry/Experimental.
