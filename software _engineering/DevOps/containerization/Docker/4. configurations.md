# ARGuments & ENVironment variables

Docker supports build-time ARGuments and runtime ENVironments variables.

`ENV` - Available inside of Dockerfile & in application code.Set via ENV in Dockerfile or via `--env` on docker run.

```js
app.listen(process.env.PORT)
```

```Dockerfile
ENV PORT 80
EXPOSE $PORT
```

```sh
docker run -p 3000:80 <img_name>
docker run --env PORT=8080 -p 3000:8080 <img_name>
docker run -e PORT=8080 -p 3000:8080 <img_name>
```

```.env
PORT=8000
```

```sh
docker run --env-file ./.env -p 3000:8080 <img_name>
```

`ARG` - Available inside Dockerfile,NOT accessible in CMD or any application code.Set on image build(docker build) via `--build-args`.

```Dockerfile
ARG DEFAULT_PORT=80
ENV PORT $DEFAULT_PORT
EXPOSE $PORT
```

```sh
docker build -t <img_name>
docker build -t <img_name> --build-arg DEFAULT_PORT=8000
```
