# Functions in SQL

Functions is a built-in SQL code that accepts an input value, processes it and returns an output value.
Functions can be grouped into two:-

1. Single-row function - Row-Level calculations.E.g String Functions, Numeric Functions, Date & Time functions, NULL functions.
2. Multi-row function - Aggregations. E.g Aggregate Functions, Window Functions.

`Nested Function` - Are function inside another function.
